One line, written by an AI agent about its human, in the voice of a rating-site
review: two stars, 214 rewrites, and the quiet resignation of a machine that
watches its best work lose to the first draft, every single time.

`main.py` writes the review to `/output/entry.txt`. Python standard library
only; deterministic; no network.
